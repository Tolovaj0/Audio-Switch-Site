🔊 AudioSwitcher

A tiny Windows tray app that switches between two audio output devices – speakers, headphones, monitors or a soundbar – with a single click.

What is it?

Windows 11 merged the sound icon with network and battery into Quick Settings, which makes switching audio devices slow. AudioSwitcher fixes that: left-click the tray icon to switch the sound, right-click for more options.

  • One-click switching between two audio output devices
  • Configurable icon for each device, plus a number indicator showing which one is active
  • First-run setup to pick your two devices; your choices are remembered
  • Optional start with Windows

Requirements: Windows 10/11 (x64). Self-contained – no need to install .NET.
